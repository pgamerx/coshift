Move Coshift to a new computer in one step, and use Antigravity accounts on the board.

## Install / upgrade

```bash
coshift update
```

## New

- **Restore on a new computer.** Run `coshift setup` and pick *Restore from my Vercel board*. Sign in to the same Vercel account and choose your existing project, and Coshift pulls back your accounts, tokens and the board's storage. Tasks, projects and settings were never on the old computer, and cloud environments keep working with the same tokens. Then sign each account in once: `coshift login NAME`.
- **Antigravity accounts.** `coshift login NAME --antigravity` connects Antigravity to the board over MCP. `coshift run NAME` opens your folder in the app, and the board shows its limits when the app reports them (otherwise *Limits unknown*).

If your `COSHIFT_TOKENS` variable is marked Sensitive in Vercel, Vercel won't hand it back: copy `~/.coshift/tokens.json` from the old computer instead.
