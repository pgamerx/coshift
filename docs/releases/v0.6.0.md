Codex joins the board. Run Claude Code and Codex (ChatGPT) accounts on one project, on your computer or on the web, with one set of instructions, an optional lead, and roles.

## Install / upgrade

```bash
npm install -g coshift@latest      # or: brew upgrade coshift
coshift deploy                     # if you have a Vercel board: update it
```

From now on, `coshift update` does both.

## New

- **Codex accounts.** `coshift login NAME --codex` adds a ChatGPT account with its own Codex sign-in. Its 5-hour and weekly limits and its context come straight from Codex's own session log, so stop lines, handovers and `coshift accounts` work with no setup. `coshift run` starts whichever account has the most limit left, Claude Code or Codex; `coshift run codex` or `coshift run claude` picks among one kind.
- **Web sessions on one board.** Claude Code on claude.ai/code and Codex on chatgpt.com/codex share the board with your desktop and CLI sessions, on the same repo. `coshift env NAME` prints the settings for both; `coshift agents` adds a short section to the repo's `AGENTS.md` and `CLAUDE.md` so every session checks in with the board.
- **Team, per project.** A new card on the board page (and `coshift team`):
  - **Shared instructions** that every session sees with every board check, edited in one place.
  - **A lead**, if you want one: it splits the work and assigns it; the others follow its plan and send disagreements to it as notes.
  - **A role per account**, in your own words.
  - Every session also gets the same working rules: work on separate things, and never change files another account's running task owns.
- **Delegation.** Any account can hand a task to another (`for_account` on `add_task` or `update_task`). The task is held for that account unless it reaches its limit.
- **`coshift update`.** Installs the newest version the way you installed Coshift (Homebrew or npm) and redeploys your Vercel board. Commands check for a new version at most once a day and print a one-line notice; `coshift update --auto on` installs updates by itself.
- **`coshift start`** works as another name for `coshift run`.
