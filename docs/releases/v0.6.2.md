Much less bandwidth for hosted boards. Every board call used to read and write the whole board (hundreds of KB), which could get an Upstash database suspended for its monthly bandwidth limit.

## Install / upgrade

```bash
coshift update
```

Update every computer that runs Coshift (the usage pusher, tray and sessions use it): older versions keep reading and writing the old whole-board copy.

## Fixed

- **Hosted boards store each task on its own.** Tasks, notes, sessions, usage and saved context now have their own small Redis keys, and a call writes only what it changed. A board status that moved a few hundred KB now reads about 20 KB, or a few hundred bytes when nothing changed since the last call.
- **Usage and context reports are tiny.** The pusher, status line and context hook write one small key, and skip it when the numbers haven't changed.
- **Project instructions are sent once per session.** board_status and claim_task say they're unchanged instead of repeating them; resume always shows them.
- **Your board moves over by itself** on the first call after the update. The old copy is kept.
- The hosted board logs how many bytes each request read and wrote, in the Vercel logs.

## Changed

- claim_task shows a task's last 20 notes and says how many older ones it left out.
- The board page lists the last 50 finished tasks.
