A polish release: a cleaner menu bar, renaming accounts, and a readable `coshift status`.

## Install / upgrade

```bash
npm install -g coshift@latest      # or: brew upgrade coshift
coshift tray                       # macOS: rebuild the menu bar app
coshift deploy                     # if you have a Vercel board: update it
```

## New

- **Rename an account everywhere.** `coshift account rename OLD NEW`, the ✎ on the board page, or the interactive menu. It renames the account on every project board, history included, and in your local files. Its token, cloud variables and env vars keep working, so there's nothing to re-paste or redeploy.
- **A redesigned menu bar.** Every row lines up with the limit meter: one left edge, one right edge, section labels for Desktop app and Coshift, and a rounded highlight. The bar shows the Coshift logo. Profiles read "Atlas · Account 1" without emojis, and **Start Forge in Claude Code** names the account with the most limit left. Board accounts show under your own profile names.
- **`coshift status` fits on one screen.** Accounts with their limits and activity, then the project's tasks with the latest note shortened; `--full` prints everything. `coshift help` is grouped by what you're doing.
