Restoring on a new computer now works when Vercel keeps your board's tokens hidden.

## Install / upgrade

```bash
coshift update
```

## Fixed

- **Restore with Sensitive tokens.** Vercel stores `COSHIFT_TOKENS` as a Sensitive value on many accounts and never hands it back, so *Restore from my Vercel board* stopped there. It now connects anyway and gives the new computer its own page key. Your existing tokens and cloud sessions stay exactly as they are; `COSHIFT_TOKENS` is never rewritten.
- **Add accounts from any computer.** On a restored computer, `coshift account add NAME` keeps the new token in the board's own storage, and the board accepts it next to the ones in Vercel.

## Changed

- Setup also keeps a copy of the tokens in the board's storage (anyone with those credentials can already read the whole board), so the next restore brings back the same tokens.
