Two fixes for running a team: an implementer account can be kept to its own tasks, and deploys explain Vercel sign-in problems.

## Install / upgrade

```bash
coshift update
```

## New

- **Assigned tasks only.** Mark an account (for example a cheap Codex implementer) as taking only tasks assigned to it: tick "Takes only tasks assigned to it" in the board page's Team card, or run `coshift team only NAME on`. The board then never hands it an unassigned task, and refuses one it names; with nothing assigned, it's told to stop and wait.

## Fixed

- **`coshift deploy` and "Error: Not authorized".** Every deploy now checks that you're signed in to Vercel first, offers `vercel login` when you aren't, and explains a refusal instead of printing Vercel's bare error. `coshift doctor` shows the signed-in Vercel account.
