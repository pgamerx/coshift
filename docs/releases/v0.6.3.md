Codex limits on the board stay current when one of your Codex logins goes stale.

## Install / upgrade

```bash
coshift update
```

## Fixed

- **Codex usage read from the Codex app too.** When a Codex account is also signed in to the Codex app (`~/.codex`), the board takes whichever reported last, matched by the ChatGPT account the session logs name (it still never reads `auth.json`). Before, it read only the account's Coshift folder.
- **Old Codex numbers no longer look fresh.** Limits are dated by when Codex recorded them, not by the log file's time. A folder whose login stopped working keeps touching its log with failed turns, which made hours-old limits show as "updated 2m ago".

If a Codex account's turns fail with "401" or "unauthorized", sign it in again: `coshift login NAME --codex`.
