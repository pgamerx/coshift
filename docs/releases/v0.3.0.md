Coshift 0.3.0 gives every project its own board, rebuilds the board page, and makes setup something you can finish without reading the docs.

## Install / upgrade

```bash
npm install -g coshift@latest      # or: brew upgrade coshift
coshift deploy                     # if you have a Vercel board: update it
```

Nothing to migrate: your current board becomes the main board.

## New

- **Projects.** Each repo can have a board of its own (`coshift project add`, or **+ New project** on the page). Sessions pick the right one from their git repo; repos without one use the main board. Account limits, settings and port ranges stay shared across projects.
- **A redesigned board page.** Accounts at the top (shared by every project), then project tabs with task counts and a dot when a session needs you, then that project's tasks. Tasks are now cards showing who's on them, what they're waiting for, the files they own and the latest note. Settings moved to the ⚙ button next to light/dark.
- **A setup checklist on the board.** Anything still missing (live usage, a desktop session, cloud sessions, the context hook, phone alerts) shows at the top and ticks itself off once the board sees it working. On a Vercel board it copies each account's cloud variables for you.
- **A clearer setup wizard.** Seven explained steps, no system question, and a guided cloud step: each account's variables one at a time, then the context hook added to your repo.
- **`coshift hook install`** adds the context hook to a repo and merges it into an existing `.claude/settings.json`.
- **Old variable names keep working.** Boards set up before the rename keep `TEAM_BOARD_URL`, `TEAM_BOARD_TOKEN` and `TEAM_BOARD_TOKENS`.
- The menu bar and tray count questions and tasks across all projects.
