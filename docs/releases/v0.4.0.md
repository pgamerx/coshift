Coshift 0.4.0 is about knowing your sessions are actually working.

## Install / upgrade

```bash
npm install -g coshift@latest      # or: brew upgrade coshift
coshift deploy                     # if you have a Vercel board: update it
coshift tray                       # macOS: rebuild the menu bar app
```

## New

- **Is it working?** Each account shows how many sessions were active in the last 3 hours, when the last one did something, and how many hold a task but have gone quiet for 15+ minutes. On the board's account cards and in the menu bar, across all projects.
- **A menu bar panel.** The macOS menu opens on every account's 5-hour and weekly bars (yellow 15 points before your stop line, red at it), their sessions, and the projects with work. **Coshift Settings…** (⌘,) opens the board's settings.
- **Account mix-up warning.** If the Claude desktop app is signed in as a different account than the switcher's name for the profile in use, the menu bar warns you, so usage and handovers don't land under the wrong name.
- **Overlap always waits.** A session adding a file to a task it already holds is refused while another running task owns that file, not just when claiming.
- **Clearer words.** "At stop line" instead of "stopped": it's about the limit, not whether a session runs.
