New session, new goal:

Use the Coshift board. Split this goal into independent tasks with add_task, then claim one and start: [describe the goal]

New session, join the work:

Use the Coshift board: report your usage, then claim and work through the open tasks. Leave notes as you go and hand over if you get near your limit.

Cloud session, continuing from the saved context (every account):

Run: curl -sS "$COSHIFT_URL/api/help" -H "Authorization: Bearer $COSHIFT_TOKEN" and follow it. Start with board resume and continue from your saved context.

Session that was already working with its own task list:

Other Claude accounts now work on this project in parallel, coordinated through the Coshift board. If you have the coshift tools (board_status, claim_task, ...), use them. Otherwise run `python3 ~/.coshift/board.py call help` and use `board.py call <tool> '<json>'` for every board action. Follow the protocol it describes. 1. Report your limits (report_usage). 2. Move your current task list onto the board: add_task for every item, with done_summary for finished ones and, for the rest, a detail another account could pick up cold. 3. Claim the task you're in the middle of and add_note where you are. 4. Leave the other tasks open for the other accounts. From now on, take new work only with claim_task.
