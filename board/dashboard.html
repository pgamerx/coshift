Starter prompts

Paste one into a Code session in either Claude window. Give each session its own worktree so their edits don't collide.

New session, new goal:

Use the Baton board. Split this goal into independent tasks with add_task, then claim one and start: [describe the goal]

New session, join the work:

Use the Baton board: report your usage, then claim and work through the open tasks. Leave notes as you go and hand over if you get near your limit.

New session, continuing from the saved context (both accounts):

Run: curl -sS "$BATON_URL/api/help" -H "Authorization: Bearer $BATON_TOKEN" and follow it. Start with board resume and continue from your saved context.

Session that was already working with its own task list:

Another Claude account now works on this project in parallel, coordinated through a shared task board. If you have the baton tools (board_status, claim_task, ...), use them. Otherwise run `python3 ~/.baton/board.py call help` and use `board.py call <tool> '<json>'` for every board action. Follow the protocol it describes. 1. Check your limits with get_usage and report them with report_usage. 2. Move your current task list onto the board: add_task for every item. For finished items pass done_summary with what you did. For the rest, write a detail that says the files/area and what done looks like, so the other account could pick it up cold. 3. Claim the task you're in the middle of and add_note where you are (done so far, next step, branch). 4. Leave the other tasks open for the other account. From now on, take new work only with claim_task.
